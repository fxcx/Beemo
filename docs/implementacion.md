# 12. Reglas de redacción SEO

NO escribir pensando únicamente en buscadores.

Escribir primero para personas.

Evitar:

* keyword stuffing
* repetir la keyword artificialmente
* frases genéricas
* contenido generado para rellenar
* afirmaciones sin fundamento
* promesas exageradas

Priorizar:

* información concreta
* ejemplos
* tablas cuando aporten claridad
* listas
* comparaciones
* casos prácticos
* preguntas frecuentes
* experiencia técnica real

La keyword principal debe aparecer naturalmente en:

* title
* H1
* introducción
* algunos H2 cuando corresponda
* URL
* meta description
* contenido
* alt text cuando sea relevante

No forzarla.
